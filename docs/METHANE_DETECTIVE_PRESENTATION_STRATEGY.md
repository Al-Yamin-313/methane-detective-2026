## 4. Technical Recording Checklist for Demonstrators

To achieve the video quality observed in top global winners like *Landsat Connect* and *Twisters*:

1. **Display Resolution:** Record screen at **1920×1080** or **1440×900** at 60 fps with 100% OS scaling (no blurry DPI fractional scaling).
2. **Clean Desktop:** Hide bookmarks bar, OS taskbar autohide, and close all background tabs.
3. **Cursor Visibility:** Enable a subtle smooth cursor ring (e.g. 24px semi-transparent circle) so viewers can follow mouse clicks naturally.
4. **Vite Dev Server Pre-warming:** Ensure `npm run dev` is running locally with tiles pre-cached so map panning is instant without gray loading squares.
5. **Microphone Setup:** Use a dedicated condenser or directional microphone with noise suppression (e.g. Audacity noise gate or OBS filter); ensure vocal levels peak between $-6\text{ dB}$ and $-3\text{ dB}$.
6. **Subtitles / Closed Captions:** Hard-code crisp, high-contrast captions centered at bottom (`Inter` or `Share Tech Mono`, white text on semi-transparent dark box) to comply with international accessibility rules.
